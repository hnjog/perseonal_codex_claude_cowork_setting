# 프로젝트 로컬 설정 양식

- 이 양식을 docs/projects 아래로 복사하고 실제 값 입력 / 완성한 설정은 Git 제외
- 프로젝트 소스 경로: [실제 절대 경로]
- 외부 작업 문서 폴더: [Contexts/docs/tasks 아래 실제 경로]
- Git·코딩 컨벤션 경로: [외부 프로젝트 설정 파일의 실제 절대 경로]
- 프로젝트별 추가 제약: [실제로 확인한 규칙]
- 사용자 거부 접근: [확인된 사례 / 없으면 없음]
- 검증 절차: [실제 프로젝트의 빌드·테스트 경로와 명령]
- 이 양식은 코드 수정·Git 상태 변경 승인 근거가 아님
- docs/projects/PROJECT_INDEX.md에 적용 조건과 실제 파일 경로 등록
