# 설치와 Contexts 폴더 운영

## 기준과 원본

- Contexts 루트를 Git 작업 트리와 공통 컨텍스트의 기준으로 사용
- AGENTS.md는 루트의 단일 원본 / 별도 공개용 복사본 유지 금지
- CLAUDE.md는 @AGENTS.md만 가져오는 얇은 진입점
- 공통 규칙 수정은 원본에서 수행 / 프로젝트 규칙은 로컬 설정에서 관리
- 세부 작업 인계·계획·분석·실제 승인 이력은 docs/tasks 또는 docs/projects에 저장
- 일반 문서 위치가 별도 지정되지 않으면 docs 내부 사용

## 프로젝트 설정

- docs/projects/PROJECT_INDEX.md를 로컬 프로젝트 진입점으로 사용
- 프로젝트별 소스 경로와 추가 지침의 실제 경로 등록
- 프로젝트별 Git·코딩 컨벤션은 docs/projects 아래에 저장
- 기존 루트 GIT_AND_CODING_CONVENTIONS.md가 있으면 실제 프로젝트 규칙으로 안내하는 로컬 호환 파일로 사용 가능
- 프로젝트 문서가 없는 새 PC에서는 templates/PROJECT_CONTEXT.example.md로 설정 준비
- 해당 프로젝트 설정과 규칙을 확인하기 전 프로젝트별 코드 수정 시작 금지

## 기존 경로 호환

- 기존에 공유한 인계·계획·분석·리뷰 경로에는 실제 새 파일 위치를 안내하는 짧은 문서 유지 가능
- 실제 내용은 새 위치 한 곳에서만 갱신 / 호환 문서에 본문 복제 금지
- 호환 문서와 원본 백업도 Git 제외
- 원본 백업은 과거 기록이며 현재 규칙으로 적용하지 않기

## 도구별 시작 경로

- Contexts에서 시작하는 Codex: 루트 AGENTS.md 사용
- Contexts에서 시작하는 Claude Code: 루트 CLAUDE.md에서 AGENTS.md 가져오기
- 다른 프로젝트 폴더에서 시작하면 사용자 홈의 전역 진입점으로 외부 Contexts 원본 연결
- 프로젝트 소스 폴더에는 AGENTS.md·CLAUDE.md 등 컨텍스트 파일 생성 금지
- Codex 전역 진입점: 사용자 홈의 .codex/AGENTS.md / 외부 원본을 직접 읽도록 지시
- Claude 전역 진입점: 사용자 홈의 .claude/CLAUDE.md / @절대경로로 외부 원본 가져오기
- 실제 전역 파일이 이미 존재하면 덮어쓰지 않고 기존 지침을 보존하여 병합
- templates의 전역 예시는 경로를 치환한 뒤 설치 / 양식 파일 자체는 활성 전역 설정이 아님
- Claude 외부 문서 가져오기의 최초 승인과 도구별 실제 파일 접근 권한 확인
- 기존 채팅은 지침을 다시 읽거나 새 세션에서 확인

## 설치 확인

- 각 도구에서 읽은 지침의 실제 경로·문서 저장 위치·코드 수정 승인 절차 요약 요청
- 코드 수정과 명령 실행 없이 규칙을 확인하는 단계로 먼저 검증
- 실제 작업 시 소스와 외부 문서 폴더에 필요한 접근 권한 확인

## Git 관리

- .gitignore는 기본 제외 방식 / 새 공통 파일은 허용 목록에 명시적으로 등록
- 실제 인계 문서와 프로젝트 설정은 로컬에서 계속 읽고 갱신 가능
- 제외 설정은 암호화나 접근 제어가 아님 / 강제 추가 사용 지양
- 이미 추적된 파일은 ignore만 추가해도 추적이 해제되지 않으므로 추적 목록 확인
- 커밋·푸시·브랜치 변경은 별도 사용자 지시 범위에서 수행
- 공통 저장소의 변경이 다른 PC에 자동 반영되지는 않음 / 갱신 작업도 사용자 지시 기준
